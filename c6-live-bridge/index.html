How commands flow

A lighting command travels left to right along the solid arrows, from the Thread network to the N4 lighting output. Confirmations and reports travel back along the dashed arrows. Arrows only animate when the gateway reports a real event.

No event outcome is inferred; the flow animates only from observed event records.
