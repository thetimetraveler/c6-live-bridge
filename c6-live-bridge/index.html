How commands flow

A lighting command travels left to right along the solid arrows, from the Thread network to the N4 lighting output. Confirmations and reports travel back along the dashed arrows. Arrows only animate when the gateway reports a real event.

No event outcome is inferred; the flow animates only from observed event records.

Lights

Each bridged lamp is checked three ways: what Lutron shows, what the bridge last sent to the Ketra hub, and what the lamp is doing according to the hub. When a Natural Show is running, the lamp is also checked against what the show calls for right now.

Brightness is light output: 0% is off, 100% is full.K is colour temperature: lower is warmer.Vibrancy is Ketra's colour saturation, 0–100.

Activity

Each row is one lighting command and the steps it went through, or a status report or query reply, newest first. Select a row to see every step.

Each step shows who sent it and who received it: Lutron → Bridge Bridge → Ketra hub Ketra hub → Bridge Bridge → Lutron. Step times are measured from when Lutron's command arrived. Asked is the level Lutron requested; Lights is the level the Ketra hub reports the lights are at. Reports without a command association are listed as status updates. Report details separate the report counter from brightness and show why each report was sent. ??? marks a value the bridge couldn't interpret, shown exactly as received.
